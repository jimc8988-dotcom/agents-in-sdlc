通过逼真的场景、完整的应用和共享待办事项，在软件开发生命周期中探索 GitHub Copilot。你将迭代地规划更改、创建代码、测试行为、审阅拉取请求并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。Tailspin Toys 是一家虚构公司，为以开发者为主题的桌游提供众筹服务。团队的待办事项已作为 GitHub issues 创建，可供你直接领取。其中既包含筛选和分页等功能开发，也包含可访问性和编码规范等质量改进。

## 选择环境

GitHub Copilot 可以伴随你在任何工作环境中使用。选择与你构建方式相符的环境。每个研讨会都从自己的设置开始，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。使用 Plan 和 Autopilot 模式、指令、技能、自定义代理、Playwright MCP、Agent Merge 和实用的斜杠命令。

### [GitHub Copilot 应用][app]

并行运行代理会话，在会话模式之间切换，在画布上协作，并管理 GitHub issues 和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub issues 分配给异步代理，指导其工作，监控进度，并审阅它打开的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。借助 Copilot Chat 的代理模式和 MCP 服务器等自定义代理，无需离开编辑器即可工作。
